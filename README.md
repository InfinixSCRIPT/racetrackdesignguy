# TrackForge 3D

Ücretsiz, tarayıcıda çalışan yarış pisti tasarımcısı. Noktalarla pistini çiz, JSON olarak indir ve 3D modda sür.

## Kullanım

1. `index.html` dosyasını GitHub Pages ile yayınla veya doğrudan tarayıcıda aç.
2. Tuvale tıklayarak noktalar ekle; noktaları sürükleyerek düzenle.
3. **Pisti kapat** düğmesine bas veya çift tıkla.
4. **3D Yarış** düğmesiyle piste gir. `WASD` / ok tuşlarıyla sür, `ESC` ile geri dön.
5. Pistini **JSON indir** ile kaydet; **JSON aç** ile geri yükle.

Three.js CDN üzerinden yüklenir; ayrıca build veya sunucu gerekmez.
